📌 About

A modern online learning platform dedicated to providing educational resources and career opportunities. The site is completely free to join and has already assisted over 250k+ students worldwide.

📄 Pages

Home — main landing page with a comprehensive overview of the platform

Login — authentication page with a secure login form

Sign Up — registration page with a user sign-up form

Courses — section featuring a catalog of available educational programs

Careers — section with up-to-date information on career growth and employment

✨ Features

🎓 Proven success — trusted and used by over 250k+ assisted students

🆓 Accessible — 100% free to join and start learning with no hidden fees

📱 Fully responsive — adapts seamlessly to all screen sizes (mobile, tablet, desktop)

🛠️ Tech Stack

React — component-based UI

React Router — declarative routing for single-page navigation

Tailwind CSS — utility-first styling
